# NICU 임상 평가용 표본 추출 기준과 인계 필수 항목 정리

- 작성일: 2026-10-16
- 대상 코드: `kcd/kcd_nicu.py`의 `sample` 명령
- 근거 자료: `nicu_handoff_required_items_v2.md`(NICU 간호 daily 인계 필수 항목 17개)

---

## 1. 목적

- 임의 평가와 임상 분석에 쓸 NICU 환아 표본을 무작위로 추출함.
- 표본 단위는 (person_id, 평가 시점)임. 평가 시점은 임상의가 기록을 보는 날짜와 시각임.
- 1일 요약지와 부모님 설명지는 평가 시점 이전 기록, 특히 직전 24시간 기록만으로 생성함.
- 직전 24시간 기록이 부족해 Core 인계 항목을 만들 수 없는 시점은 표본에서 제외함.

## 2. 실행 방법

```bash
python kcd_nicu.py sample --data datasets/kmimic-emr-001/268 --n 100 --seed 0 --out sample
```

```bash
python kcd_nicu.py sample --data datasets/kmimic-emr-001/268 --n 100 --seed 0 --stratify --out sample
```

```bash
bash sample/nicu_sample_commands.sh
```

- `--stratify`는 생후일 구간(0~3일, 4~7일, 8~14일, 15~28일)별로 같은 수를 뽑음.
- `--seed`를 고정하면 같은 표본이 다시 나옴.
- 세 번째 명령은 표본마다 1일 요약지와 부모님 설명지를 생성함.

## 3. 선정 조건

평가 시점 후보는 NICU 재실 중 매일 07:00임. 아래 조건을 순서대로 적용함.

| 단계 | 조건 | 기준값(기본) | 관련 인계 항목 | 설정 이유 |
|---|---|---|---|---|
| 1 | NICU 코호트 | 병동명에 NICU·신생아 포함 또는 나이 0세 | - | 대상 정의 |
| 2 | 출생 시각 확인 가능 | 생년월일 컬럼 또는 근사 가능 | 1. 식별(생후일) | 생후 28일 판정에 필요 |
| 3 | 직전 24시간 전체가 NICU 재실 중 | 입실 후 24시간 이상 경과, 퇴실 전 | 전 항목 | 전날 데이터 전체가 같은 재실 기간 안에 있어야 함 |
| 4 | 생후 28일 이하 | 출생일 = 0일, 28일 이하 | - | 신생아기 정의 |
| 5 | 사망 이전 시점 | 사망 시각 이전 | - | 사망 후 시점 제외 |
| 6 | 활력징후 기록 충분 | HR 6건, SpO2 6건, 체온 2건, 혈압 1건 이상 | 3. 호흡, 5. 무호흡·서맥·탈포화, 6. 순환, 7. 체온 | 범위·사건 횟수를 계산할 최소 기록 |
| 7 | 체중 기록 | 평가 시점 이전 7일 안 | 1. 현재 체중, 10. 체중 변화 | mL/kg 계산에 필요 |
| 8 | 섭취 기록 | 직전 24시간 1건 이상 | 9. 영양, 8. 주입 내용 | 수유·수액량 계산에 필요 |
| 9 | 소변 기록 | 직전 24시간 1건 이상 | 10. 소변량(mL/kg/h) | 소변량 계산에 필요 |

- **HR·SpO2 6건**은 4시간 간격 측정에 해당함.
- **검사와 투약은 필수 조건에서 뺐음.** 매일 검사하거나 투약하지 않는 환아도 정상 대상이기 때문임. 대신 건수를 출력해 분석에 쓸 수 있게 함.
- **한 환아당 한 시점만 뽑음.** 같은 환아의 여러 날이 표본을 차지하지 않게 하기 위함임. 적격 시점 중 하나를 무작위로 고름.
- **모든 기준값은 바꿀 수 있음.** 병원 프로파일 JSON의 `sampling` 항목으로 조정함. 예: `{"sampling": {"min_bp": 0}}`

## 4. 출생 시각 판정

- **생년월일 컬럼이 있으면 그 값을 씀.** PATIENTS의 `dob`, `birth_datetime`, `birthdate`, `birth_time`, `date_of_birth` 중 하나임.
- **K-MIMIC 공개 문서에는 생년월일 컬럼이 없음.** 이 경우 입원 시각을 출생 시각으로 근사함.
- 근사는 두 조건을 모두 만족할 때만 씀. 나이(anchor_age)가 0세이고, 입원 후 48시간 안에 NICU에 입실한 경우임.
- 이 근사는 원내 출생아에 맞음. 외부 출생 후 전원된 환아는 생후일이 실제보다 작게 계산될 수 있음.
- 결과 파일의 `birth_source` 열에 출처가 남음. 출처별로 나누어 민감도 분석을 할 수 있음.

## 6. 인계 필수 항목 정리 (nicu_handoff_required_items_v2.md)

### 가. 원문 요약

- 구성: 17개 영역. Core(항상 필수) 13개, 조건부(원자료에 기록이 있을 때 필수) 4개.
- 5번(무호흡·서맥·탈포화)은 미숙아에서 Core임.

|---|---|---|---|

| 2 | 중증도 | 안정·관찰 필요·불안정, 활성 문제 목록 | Core |
| 3 | 호흡 | 지지 방식(기계환기 모드·설정, CPAP·HFNC), FiO2, SpO2 목표 범위, 최근 혈액가스 | Core |
| 4 | 기도·튜브 | ETT 크기, 고정 깊이(cm), OG·NG 위치 | Core |
| 5 | 무호흡·서맥·탈포화 | 근무조 내 사건 횟수, 중재 강도, 카페인 투여 여부 | Core(미숙아) |
| 6 | 순환 | HR·BP 범위, 관류, 혈관작용제(약물·용량·속도) | Core |

| 11 | 투약 | 정규 투약 시각, 마지막 투여 시각, 투여 상태와 사유, 고위험약 | Core |

| 16 | 피부 | 기구 관련 압박손상, 테이프 손상, 침윤 부위 | 조건부 |

### 나. K-MIMIC 구조화 데이터로 채울 수 있는 정도

- 판정 기준은 K-MIMIC 공개 문서와 Synthetic K-MIMIC(SYN-ICU) 사전에서 확인한 테이블·항목임.
- 실제 SNUH 데이터의 D_ITEMS에 간호 기록 항목이 더 있을 수 있음. `profile-check` 명령으로 병원 데이터에서 다시 확인해야 함.
- 표기는 다음과 같음.
  - **가능:** 구조화 데이터에서 자동 생성 가능
  - **부분:** 일부 하위 항목만 가능하거나 근사값
  - **없음:** 원자료에 없어 "확인 필요"로 표시

| 번호 | 영역 | 판정 | 데이터 근거 | 현재 코드 반영 |
|---|---|---|---|---|
| 1 | 식별 | 부분 | 식별자(subject_id)와 현재 체중·측정일은 CHARTEVENTS에서 가능. 생후일은 입원 시각 근사. GA·출생체중·교정연령·다태아 순번은 확인되지 않음 | 체중·입원일수 자동, GA·출생체중은 확인 필요로 표시 |
| 2 | 중증도 | 부분 | 진단코드(청구 기준)와 CDSS 알림으로 활성 문제 구성 가능. 안정·관찰·불안정 분류는 규칙으로 산출해야 함 | 진단·알림은 반영, 중증도 3단계 분류는 미구현 |
| 3 | 호흡 | 부분 | 모드·PEEP·FiO2·산소유량은 CHARTEVENTS, 혈액가스는 LABEVENTS. SpO2 목표 범위는 기록 항목이 확인되지 않음 | 호흡 보조와 모드 변경 반영, 혈액가스는 24시간 내 검사에 포함 |
| 4 | 기도·튜브 | 없음 | ETT 크기·깊이, OG·NG 위치의 구조화 항목이 확인되지 않음. 삽관 시술 기록과 OG 섭취 경로만 있음 | 미반영 |
| 5 | 무호흡·서맥·탈포화 | 부분 | 사건 횟수는 SpO2·HR 기록값으로 근사. 중재 강도는 없음. 카페인은 EMAR | 사건 횟수(24시간)와 카페인 반영 |
| 6 | 순환 | 부분 | HR·BP 범위와 혈관작용제(EMAR 주입속도)는 가능. 관류(CRT 등)는 확인되지 않음 | 반영(관류 제외) |
| 7 | 체온·환경 | 부분 | 체온 범위는 가능. 인큐베이터 모드·습도는 확인되지 않음 | 체온 범위와 체온 불안정 알림 반영 |
| 8 | 수액·라인 | 부분 | 라인 종류·첫 기록일은 PROCEDUREEVENTS 기록이 있을 때 가능. 주입 내용·속도는 EMAR·INPUTEVENTS. 깊이·부위 상태는 없음 | 라인 기록과 유지일 알림 반영 |
| 9 | 영양·위장 | 부분 | 경로(정맥·경관·경구)와 양은 INPUTEVENTS. 수유 종류·증량 계획·불내성은 확인되지 않음 | 섭취량·mL/kg/일·경로 반영 |
| 10 | 배설·대사 | 가능(광선요법 제외) | 소변·대변(OUTPUTEVENTS), 혈당·빌리루빈(LABEVENTS·BST), 체중 변화 | 반영. 광선요법은 시술 기록이 있을 때만 |
| 11 | 투약 | 부분 | 마지막 투여 시각과 고위험약은 EMAR. 미투여·보류 상태와 사유는 확인되지 않음 | 투여 중·오늘 시작·오늘 중단 반영 |
| 12 | 신경·통증 | 없음 | 활동성·경련·통증 점수의 구조화 항목이 확인되지 않음 | 미반영 |
| 13 | 미결 사항 | 부분 | 결과 대기 배양은 MICROBIOLOGYEVENTS. 예정 검사·시술은 없음 | 미보고 배양 반영 |
| 14 | 비상 계획 | 없음 | 원자료 없음 | 생성하지 않음(조건부 항목) |
| 15 | 가족 | 없음 | 원자료 없음 | 생성하지 않음(조건부 항목) |
| 16 | 피부 | 없음 | 원자료 없음 | 생성하지 않음(조건부 항목) |
| 17 | 감염·격리 | 부분 | 배양 대기는 가능. 격리 여부는 다제내성균 배양 결과로만 추정 | 미보고 배양·격리 확인 필요 반영 |

### 다. 표본 추출 조건과의 관계

- 표본 조건 6~9단계는 위 표에서 "가능·부분" 판정을 받은 Core 항목의 원자료임.
  - 6단계: 호흡·순환·체온 항목
  - 7단계: 식별의 현재 체중
  - 8단계: 영양 항목
  - 9단계: 배설 항목
- "없음" 판정 항목(4, 12번과 조건부 14~16번)은 기록 유무로 표본을 거르지 않음. 데이터에 없으므로 모든 시점에서 "확인 필요"로 표시됨.
- 따라서 이 항목들은 생성 문서의 누락 평가에서 따로 집계해야 함. 데이터 공백과 생성 누락을 구분하기 위함임.

### 라. 코드 반영 상태

- **반영 완료:** 기본 체크리스트를 md 17개 영역, 50개 세부 항목으로 바꿈. 표에 영역 번호가 표시됨.
  - Core 항목은 데이터에 없으면 "확인 필요"로 표시함.
  - 조건부 영역(14~17)은 기록이 있을 때만 넣음.
  - 5번(무호흡·서맥·탈포화)은 미숙아 진단코드(P07)가 있는 환아에게만 필수로 둠.
  - ETT 항목은 침습적 인공호흡 중일 때, OG·NG 위치는 위관 섭취 기록이 있을 때만 필수로 둠.
- **반영 완료:** 중증도 3단계 분류(2번)를 추가함. 판정 규칙은 다음과 같고, 근거가 기록지에 함께 표시됨.
  - 불안정: 고위험 알림, 침습적 인공호흡, 혈관작용제 투여 중 하나
  - 관찰 필요: 중간 알림, 비침습 호흡 보조·산소, 무호흡·서맥·탈포화 기록 중 하나
  - 안정: 위 조건에 해당하지 않음
  - 규칙은 프로파일 `severity`에서 수정함.
- **반영 완료:** 최근 혈액가스(3번)는 24시간 창 밖이어도 72시간 안의 가장 최근 값을 넣음.
- **반영 완료:** EMAR의 미투여·보류 기록을 투여 상태(11번)로 넣음.
- **남은 일:** 5번 사건 횟수는 아직 24시간 단위임. md 기준인 근무조 단위로 나누려면 프로파일에 근무조 시각을 두어야 함.
- **남은 일:** 4, 12, 16번은 실제 데이터에서 다시 확인해야 함. `profile-check`로 D_ITEMS 라벨을 찾고, 있으면 `chart_regex` 출처로 연결함.
